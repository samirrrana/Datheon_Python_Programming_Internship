# Colorful Hangman Game

A terminal-based Hangman word guessing game built using Python, featuring vibrant ANSI colors, dynamic ASCII gallows art, and external text file word loading.

## File Structure
* `hangman.py` - Main game source code with colorful terminal UI.
* `words.txt` - Text file containing vocabulary words for the game.
* `README.md` - Project documentation.

## How to Run
1. Make sure you have `words.txt` and `hangman.py` in the same folder.
2. Open your terminal or command prompt.
3. Run the game using:
   ```bash
   python hangman.py
   ```
